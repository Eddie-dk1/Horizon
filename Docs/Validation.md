# Проверки Horizon 0.3

Среда проверки: Apple Silicon, macOS, Swift 6. Проверки ядра и модели приложения работают на отдельных временных хранилищах с синтетическими данными. Пользовательские файлы и каталоги хранилищ в репозиторий не входят.

## Автоматические проверки

```bash
bash Scripts/test.sh
bash Scripts/test-space.sh
bash Scripts/test-interactions.sh
```

Ядро: 17 сценариев. Проверяются известные векторы PBKDF2, AES-GCM и HKDF; пароли, Unicode и восстановление; потоковая обработка и границы блока; повреждение, усечение и перестановка блоков; атомарность записи, отмена и изменение источника; папки и Корзина; резервные копии; переход каталога v1 → v2; сохранение независимых координат Space. На чистой копии исходников для репозитория 9 октября 2026 года повторно прошли все 17 проверок, 0 ошибок.

Space: 250 записей, устойчивость сохранённых позиций, камера при разных масштабах, группа потомков галактики, траектории появления файлов, категории звёзд, порог жеста, отмена через Escape, зум с удержанием точки под указателем и загрузка локальных адресов через NSItemProvider.

Модель приложения: выход из вложенной галактики на один уровень, защита навигации за диалогом и предпросмотром, фиксированное назначение асинхронного сброса, пакетный импорт, события успешной записи, сохранение координат и отмена отложенных действий предыдущей сессии.

Дополнительный тест требует свободного места и не входит в обычный прогон:

```bash
HORIZON_LARGE_TEST=1 bash Scripts/test.sh --filter largeFileOverFourGiB
```

Импорт и экспорт файла 4 ГиБ + 17 байт ранее прошли поблочное сравнение с исходником.

## Ручная проверка

В демонстрационном пространстве проверялись вход, системные окна выбора и сохранения, предпросмотр, заметки, повторный вход, резервная копия и восстановление. Для Space проверялись перемещение галактики с потомками, независимая локальная карта, перемещение файла к точке отпускания, масштабирование кнопками, возврат всех записей в кадр, появление файла после commit и выход из галактики по Escape при фокусе окна и поиска.

Локальная сборка проверяется через `codesign --verify --strict` и `plutil -lint`.

## Ограничения проверки

- Реальная потеря питания и переполнение диска не воспроизводились; используются внедрённые ошибки записи.
- Физический жест трекпада, полный перенос файлов между окнами Finder и приложения, сон и смена пользовательской сессии требуют дополнительного ручного прогона.
- Дерево Accessibility и действия клавиатуры проверялись; сеанс с включённым VoiceOver не проводился.
- Независимый аудит криптографической реализации, Developer ID и нотарификация Apple не заявляются.

Формат хранения и границы защиты описаны в [Storage.md](Storage.md).
