# Horizon

Личное зашифрованное хранилище для Mac. **Space** — карта светящихся звёзд: файлы и заметки становятся звёздами, а папки — маленькими спиральными галактиками вокруг чёрной дыры.

## Запуск

Откройте `build/Horizon.app`. При желании скопируйте приложение в Applications. Требуются Apple Silicon и macOS 14 или новее. Первый запуск предлагает создать пароль и сохранить ключ восстановления отдельно от Horizon.

Это локальная сборка с подписью ad hoc, без нотарификации Apple и автоматического обновления.

## Space

- Наведите указатель на звезду, чтобы увидеть название и тип записи; нажмите для открытия.
- Все активные записи, включая содержимое папок, доступны на общей карте. Связи показывают принадлежность папкам.
- Нажатие на галактику плавно приближает к папке. Её файлы раскрываются звёздами вокруг галактики в центре. Вложенные папки открываются так же; `Esc` возвращает на один уровень выше, до общей карты Space. Также можно вернуться по цепочке навигации вверху. Во время перетаскивания `Esc` сначала отменяет жест.
- Перетаскивайте звёзды и галактики для свободного размещения; движение начинается после 6 пунктов. `Esc` отменяет текущий жест. Расположение сохраняется в зашифрованном каталоге после отпускания.
- На общей карте галактика движется вместе со всеми активными потомками. Внутри галактики расположение независимое: движение меняет только выбранную запись. Перенос между папками выполняется через «Переместить…».
- `⌥` + стрелка сдвигает объект в фокусе на 20 экранных пунктов. Те же четыре действия доступны через Accessibility. В Корзине перестановка отключена.
- Перетаскивайте фон для перемещения карты. Масштаб меняется сведением и разведением двух пальцев на трекпаде по всей области Space, включая звёзды, и кнопками внизу справа. Зум сохраняет точку карты под указателем.
- Кнопка со стрелками «Показать все звёзды» плавно сбрасывает смещение и масштаб, размещая содержимое текущего раздела в окне. У карты нет прежнего ограничения в шесть записей.
- Счётчик внизу отдельно показывает звёзды (файлы и заметки) и галактики (папки) текущего раздела, например «11 звёзд и 1 галактика».
- Поиск работает по названиям; результаты остаются звёздами.
- Изображения — голубые шестилучевые звёзды, документы — белые четырёхлучевые, заметки — янтарные восьмилучевые, аудио и видео — лавандовые с ореолом, прочие файлы — компактные серебристые. Категория определяется по расширению без чтения содержимого.
- Сброшенные файлы появляются возле точки сброса; пакет образует небольшую группу. Добавление через кнопку выбирает свободное место. После проверенной записи световая точка вылетает из центра и превращается в звезду. Одновременно летят не более трёх точек; остальные появляются коротким проявлением. Уменьшение движения отключает полёт.
- Положения переживают блокировку, перезапуск и восстановление копии. Камера между запусками не сохраняется; при входе она показывает всю карту.
- Меню около названия Space содержит Заметки, Папки и Корзину. Все разделы используют карту звёзд.
- Настройки — маленькая кнопка шестерёнки рядом с замком.
- Контекстное меню звезды: экспорт, переименование, перемещение и удаление; в Корзине — восстановление и окончательное удаление.

## Возможности

- Локальное шифрование файлов, названий, папок, заметок и Корзины.
- Перетаскивание и пакетное добавление файлов; оригиналы остаются на месте.
- Вложенные папки, перемещение, переименование, поиск по названиям.
- Заметки с автосохранением через 500 мс и сохранением через ⌘S.
- Просмотр изображений, PDF и UTF-8 текста в памяти.
- Потоковый экспорт с проверкой целостности.
- Корзина на 30 дней; восстановление и окончательное удаление.
- Зашифрованные резервные копии `.horizonbackup`.
- Восстановление через пароль или ключ с сохранением предыдущего хранилища.
- Смена пароля, автоблокировка, поддержка уменьшения движения.

## Основные действия

| Действие | Способ |
|---|---|
| Добавить файлы | Перетащить в Space, меню + или ⌘O |
| Открыть запись | Нажать звезду |
| Создать заметку | + → «Новая заметка» или ⌘N |
| Создать папку | + → «Новая папка» или ⇧⌘N |
| Сохранить заметку | Автоматически или ⌘S |
| Заблокировать | Значок замка или ⌘L |
| Настройки | Шестерёнка рядом с замком или ⌘, |
| Резервная копия | Настройки или системное меню Space |
| Восстановить копию | Экран входа → «Восстановить копию» |

Horizon блокируется при сне, смене пользовательской сессии, скрытии приложения, сворачивании и закрытии главного окна. Таймер бездействия: 1, 5, 15 или 30 минут; по умолчанию 5.

## Где находятся данные

По умолчанию: `~/Library/Application Support/Horizon`. Открыть каталог можно из настроек. Обновление или удаление `.app` не удаляет эти данные. Файлы проекта и личное хранилище разделены.

Horizon 0.3 использует каталог версии 2. При первом открытии прежнего каталога приложение проверяет отдельную зашифрованную копию, назначает позиции и переключает активное хранилище. Сбой до переключения сохраняет исходное состояние. Старые резервные копии поддерживаются; после обновления каталога используйте Horizon 0.3 или новее.

При обновлении формата и восстановлении предыдущее хранилище остаётся в каталоге данных. После проверки новой копии его можно явно удалить через настройки.

## Ограничения и важное поведение

- Поддерживается импорт обычных файлов. Импорт физических папок, ссылок и пакетов macOS пока не предусмотрен.
- Добавление создаёт копию: **оригинал остаётся доступным снаружи**.
- Экспорт создаёт обычный незашифрованный файл в выбранном месте. После экспорта он не защищён паролем Horizon.
- Заметка: до 1 МиБ UTF-8. Предпросмотр: до 32 МиБ входных данных; изображения до 40 мегапикселей; текст отображается до первого 1 МиБ.
- Большие файлы хранятся и экспортируются блоками по 4 МиБ; размер не ограничен пределом предпросмотра.
- Каталог рассчитан максимум на 100 000 записей и 64 МиБ зашифрованных метаданных. Для плотной карты используйте поиск и масштабирование.
- Без пароля и ключа восстановления получить доступ невозможно. Ключ не отправляется на сервер.
- Смена пароля не меняет пароль старых резервных копий и не отзывает уже скопированные данные.
- Окончательное удаление не гарантирует физическое стирание с SSD; резервные копии могут сохранять запись.
- Открытые данные находятся в памяти приложения. Horizon не защищает от наблюдения за открытым экраном или вредоносного ПО с доступом к вашей сессии.
- Если заметка не сохранилась из-за ошибки диска, блокировка оставляет зашифрованный черновик только в памяти. При обычном выходе приложение предупреждает; принудительное завершение теряет этот черновик.

## Сборка и проверки

Достаточно Command Line Tools со Swift 6. Внешние пакеты не нужны.

```bash
bash Scripts/build.sh
bash Scripts/test.sh
bash Scripts/test-space.sh
bash Scripts/test-interactions.sh
HORIZON_LARGE_TEST=1 bash Scripts/test.sh --filter largeFileOverFourGiB
```

Результат сборки: `build/Horizon.app`, `build/Horizon-macOS.zip`. Иконка создаётся из `Scripts/icon.swift`; исходный PNG 1024 × 1024 сохраняется в Resources.

Используется самостоятельный проверочный executable: XCTest и отдельный runtime Swift Testing не требуются. Проверки ядра запускаются на временных хранилищах и не затрагивают личные данные. Проверка Space охватывает более шести записей, сохранение позиций, размещение всей карты в окне и центрирование выбранной галактики при приближении.

## Тестовое пространство

На экране входа есть кнопка «Открыть тестовый Space». Выбор запоминается при обычном повторном запуске. Над полем входа и на карте явно указано, что открыт тестовый Space. Для личного хранилища выберите «Личный Space» на экране входа.

Закройте Horizon и запустите его с отдельным демонстрационным хранилищем:

```bash
open build/Horizon.app --args --vault-root "$PWD/work/ui-vault"
```

Пароль демонстрационного хранилища: `horizon demo password`. Это пространство предназначено для тестирования. Демонстрационный пароль и синтетические пароли проверок являются частью исходного кода; не используйте их для личных данных. Пока выбран тестовый режим, обычный запуск также открывает его. Личный каталог в Application Support используется после выбора «Личный Space».

Спецификация формата и границы гарантий: `Docs/Storage.md`. Отчёт проверки: `Docs/Validation.md`.
